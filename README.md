FL Atlas Launcher V2 is a modern launcher for Freelancer players who manage multiple installations, multiplayer identities, mods, and universe data from one place.

The launcher focuses on a smooth sci-fi cockpit experience, safe MPID handling, fast game startup, and useful map and trade tools for everyday play.

![FL Atlas Launcher cockpit](assets/launcher_v086_screenshot.jpg)

## Download

Get the latest Windows package from the [GitHub Releases page](https://github.com/flathack/FL-Atlas-Launcher/releases/latest).

## Key Features

- Manage multiple Freelancer installations from one launcher.
- Save, switch, and protect multiplayer identities.
- Detect unknown active registry IDs before they can be overwritten.
- Apply common Freelancer fixes and quality-of-life tweaks.
- Explore systems, bases, stations, jump gates, jump holes, fields, and routes.
- Analyze trade routes and plan paths through the universe.
- Check for launcher updates directly in the app.

## Status

FL Atlas Launcher V2 is a stable release. New features continue to be tested across different Freelancer mods and installations.
