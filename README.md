# FL Atlas Launcher

FL Atlas Launcher is a small desktop launcher for Freelancer players who manage multiple installations, mods, MPIDs, display settings, trade data, and tooling.

## Download

Get the latest builds from the GitHub Releases page:

https://github.com/flathack/FL-Atlas-Launcher/releases/latest

Current release: v0.4.8

Available builds:

- Windows x64
- Windows arm64
- Linux x86_64

## What It Does

- Manage multiple Freelancer installations
- Store and switch MPID profiles
- Adjust resolution and launch Freelancer
- Detect running game instances
- View trade routes, ship information, and universe data
- Support Windows first, with Linux builds available

## Updates

The launcher checks GitHub Releases for updates. Release metadata is also available in `latest.json` for tooling that prefers a stable JSON endpoint.
