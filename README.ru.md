FL Atlas Launcher V2 — современный лаунчер для игроков Freelancer, которые управляют несколькими установками, multiplayer identities, модами и данными вселенной из одного места.

Лаунчер ориентирован на плавный sci-fi cockpit-интерфейс, безопасную работу с MPID, быстрый запуск игры и полезные инструменты карты и торговли для повседневной игры.

![FL Atlas Launcher cockpit](assets/launcher_v086_screenshot.jpg)

## Скачать

Актуальный Windows-пакет доступен на [странице GitHub Releases](https://github.com/flathack/FL-Atlas-Launcher/releases/latest).

## Основные возможности

- Управление несколькими установками Freelancer из одного лаунчера.
- Сохранение, переключение и защита multiplayer identities.
- Обнаружение неизвестных активных registry IDs до того, как они могут быть перезаписаны.
- Применение распространенных исправлений Freelancer и удобных настроек.
- Изучение систем, баз, станций, jump gates, jump holes, fields и маршрутов.
- Анализ торговых маршрутов и планирование пути по вселенной.
- Проверка обновлений лаунчера прямо в приложении.

## Статус

FL Atlas Launcher V2 сейчас находится в beta-релизе. Возможны активные изменения, пока функции дорабатываются и тестируются с разными модами и установками Freelancer.
